=== Model ===
```
constexpr int kMaxParams = 160, kMaxGroups = 40;
struct Model {
    const Host* host = nullptr;
    uint8_t mode = 0;                 // 0 = Program, 1 = Combination
    uint8_t program = 0, combi = 0;   // current numbers
    uint8_t progEdit[143] = {0};      // the edit buffers the engine plays from
    uint8_t combiEdit[124] = {0};
    bool edited = false, comparing = false, shift = false;
    m1::ParamDef params[kMaxParams];  // flattened parameters of the current mode
    int nParams = 0;
    char groupName[kMaxGroups][12];   // group titles
    uint8_t groupFirst[kMaxGroups];   // index of the group's first param in params[]
    int nGroups = 0;
    int group = 0;                    // current group
    int sub = 0;                      // index within the group of the first of the 4 shown params (multiple of 4)
};
```
=== Functions (all `inline`, taking `Model& m`) ===

- `void buildPages(Model& m)`: rebuild params/groups for the current mode, then clamp `group` to [0,nGroups-1] and `sub` to a valid multiple of 4. PORT of Pico's buildEdit, simplified (no padding, no Global/Kit): for each page `pg` in programPages (mode 0) or combiPages (mode 1): skip it if mode==0 && (pg.flags & m1::kPageDoubleOnly) && block[10] != 1; if (pg.flags & (m1::kPageFx1|m1::kPageFx2)): k = (flags & kPageFx1) ? 0 : 1; fxBase = mode==0 ? m1::kProgFx : m1::kCombiFx; type = block[fxBase + k]; group title = "FX<k+1> <kFxNames[type<34?type:33]>"; params = the 8 entries of `m1::effectParams(type)` (fp[0..7]), each added with offset adjusted by `fxBase + 9 + 8*k`; entries with a null `name` are skipped; continue to the next page. If (pg.flags & m1::kPageTimbre): for timbre tm=0..7: new group titled "Timbre <tm+1>", add all pg.params with offset + 11*tm; continue. Otherwise: new group titled pg.title, add all pg.params with null-name entries skipped. "Adding" a param means: copy the ParamDef into params[nParams] with `offset = (uint8_t)(p.offset + dOff)`; ignore when nParams >= kMaxParams or nGroups >= kMaxGroups. Group titles are copied with snprintf into groupName (11 chars max). A group with zero params must not be created (remove it / do not start it until the first param is added).
- `int groupCount(const Model&)`, `int groupSize(const Model& m, int g)` (= next group's first - this first, or nParams - first for the last).
